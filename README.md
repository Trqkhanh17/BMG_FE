# Frontend — Bốn Mùa Gió

React + Vite user interface. The slide assets are in `public/images/` and load in numeric order from 1 through 22. The only input fields are on slides 2, 21, and 22; there is no form on the other slides.

From this folder run:

```powershell
npm install
npm run dev
```

Build with `npm run build`.
